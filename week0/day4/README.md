
# Salesforce Automation

## What is Flow Builder?
Flow Builder is a Salesforce automation tool used to automate business processes without coding.

---

# Types of Flows

## Screen Flow
- Requires user interaction
- Used for forms and guided processes

### Example
Student admission form

---

## Record Triggered Flow
- Runs automatically when records are created or updated

### Example
Send email after student registration

---

# Automation Benefits
- Saves time
- Reduces manual work
- Improves productivity
- Maintains consistency
- Reduces errors

---

# Manual vs Automated Systems

## Manual System
- Human dependent
- Slower process
- More chances of mistakes

## Automated System
- Faster processing
- Less manual effort
- Better accuracy

---

# Real World Automation Examples
- Auto email notifications
- Attendance reminders
- Fee payment alerts
- Course seat updates
- Student ID generation
