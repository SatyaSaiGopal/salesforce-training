# Task 3: Manual vs Automated Process

## Manual Process
Staff manually verifies student registration and sends confirmation emails.

### Problems
- Time consuming
- Human errors
- Delayed communication
- Difficult to track records

## Automated Process
Salesforce Flow automatically sends confirmation emails and updates records.

### Benefits
- Faster processing
- Consistent communication
- Reduced workload
- Better record tracking

# Task 4: Reflection

Companies should automate repetitive business processes because automation improves efficiency, reduces errors, saves employee time, and helps organizations scale operations effectively.
