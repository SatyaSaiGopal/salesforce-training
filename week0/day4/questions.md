# Reflective Questions – Salesforce Automation

---

## 1. Why do companies automate workflows?

Companies automate workflows to save time, reduce manual effort, and improve efficiency. Automation helps complete repetitive tasks quickly and ensures processes run smoothly without human intervention.

---

## 2. What problems happen with manual processes?

Manual processes can lead to:
- Human errors
- Delays in work
- Inconsistent results
- Increased workload
- Difficulty in tracking tasks

---

## 3. Difference between Screen Flow and Record-Triggered Flow

Screen Flow:
- Requires user interaction
- Displays screens to collect input
- Used for guided processes

Record-Triggered Flow:
- Runs automatically in the background
- No user interaction needed
- Triggered when a record is created or updated

---

## 4. Why is no-code automation powerful?

No-code automation is powerful because it allows non-developers to build solutions quickly without programming. It speeds up development, reduces dependency on developers, and makes systems easier to maintain.

---

## 5. When should automation be avoided?

Automation should be avoided when:
- The process is very complex
- Frequent changes are required
- Human decision-making is important
- The logic is not clearly defined

---

## 6. How does automation improve consistency and productivity?

Automation ensures that tasks are performed the same way every time, reducing errors and maintaining consistency. It also saves time by handling repetitive work, allowing employees to focus on more important tasks, thus improving productivity.
